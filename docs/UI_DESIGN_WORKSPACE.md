# UI 设计工作区

本轮将 UI 工作区从 `App.jsx` 拆出到 `src/features/ui-editor/`，沿用编辑器深色工具栏与橙色图标，重新设计图层、组件模板、画布和属性面板。

## 使用

- 左侧“图层”支持搜索、选择和独立显隐；“组件与模板”提供文本、容器、按钮、图片及明暗两套运营模板。
- 模板应用可撤销。图片支持本地导入，单张上限 3 MB。
- 画板采用真实像素坐标，自动适应中间可用空间。可放大、缩小、恢复适应窗口，显示网格和启用 8px 位置吸附。
- 选中图层可拖拽、八方向调整尺寸、编辑名称/文字/字号/字重/填充/圆角/透明度，或按画板左右居中对齐、调整前后层级。
- 方向键移动 1px，Shift + 方向键移动 10px，Ctrl/Cmd D 复制，Delete 删除，Ctrl/Cmd Z 撤销，Ctrl/Cmd Shift Z 重做。
- “预览画板”隐藏选中框与手柄，禁止画板拖动修改；Esc 返回编辑。
- UI 撤销历史独立于三维对象历史，最多保留 40 步，刷新后清空。

## 旧数据与导出

旧画布先将画板限制为约 720×480 的内部显示空间，再做缩放；V2 改为画板真实宽高，缩放只影响视口。已有自定义节点按旧内部缩放比例迁移，迁移是幂等的。未修改的初始三组件示例会升级到新运营模板。

首次迁移前，旧数据会保存到浏览器 `frame-ui-legacy-backup`，不覆盖已有备份。节点、画板、模板仍使用原存储键，另增加 `frame-ui-version=2`。没有显式版本的旧 JSON 视作 V1。

编辑器与 React/Vue 导出共用 `uiNodeStyle`。导出使用百分比布局与容器宽度单位，将字体、圆角等随画板一起缩放，保留图片、背景、透明度等属性。需要支持 CSS 容器单位的浏览器。

运营模板中的指标、图表和任务是可编辑示例图层，没有连接真实业务数据或按钮动作。

## 验证

`node --test tests/*.test.js` 覆盖模板几何范围、唯一 ID、旧数据迁移、吸附边界、导出样式和生成的 React JSX/TSX 语法；同时运行 `npm run build` 并在浏览器验证编辑、撤销重做、拖拽与预览。
