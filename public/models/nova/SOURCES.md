# NOVA scene assets

Downloaded 2026-10-18. Original source README files are preserved alongside each model.

- **RobotExpressive.glb**: Tomás Laulhé (Quaternius), modifications by Don McCurdy. CC0 1.0. [Source and license](https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf/RobotExpressive).
- **ToyCar.glb**: Guido Odendahl (original model), Eric Chadwick (materials and scene composition). CC0 1.0. [Source and license](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/ToyCar).

The deck, platforms, rings, energy core, lights and composition are built from editable editor primitives. Models are served locally; opening the demo does not require contacting either source repository.

Use the editor's **NOVA 示例** button to load the scene. The previous scene is backed up locally and can be recovered with **文件 → 恢复示例前的场景**. The JSON preset is also available at `/scenes/NovaLab.scene.json`.
