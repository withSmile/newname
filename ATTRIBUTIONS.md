# Third-party test assets

The files in `public/models` are development and interoperability test assets from the Khronos glTF Sample Assets repository. They are not original project artwork.

- `Box.glb`: Khronos glTF Sample Assets, see the source model README.
- `DamagedHelmet.glb`: Damaged Helmet sample, CC BY 4.0. Source: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/DamagedHelmet
- `Fox.glb`: Fox model by PixelMannen and animations/conversion by Autodesk/Khronos contributors, CC0 and CC BY 4.0 components. Source: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox
- `CesiumMan.glb`: Cesium Man, CC BY 4.0, containing Cesium branding. Source: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CesiumMan

Review each linked model README before redistributing or using these assets outside development/testing.
